## 🎯 Project Overview
Hearing-impaired children face challenges in communication, emotional expression, and safety awareness.  
This system bridges these gaps using **AI-driven sign recognition, emotion detection, and hazard sound alerts** to create an **inclusive, interactive learning experience**.

---

## ✨ Key Features
✅ **Multilingual Sign Recognition** – Real-time translation between ASL, BSL, and LSL  
✅ **Interactive Learning** – Engaging sign practice with quizzes and gesture feedback  
✅ **Emotion Detection** – Recognizes emotions via facial and hand movement analysis  
✅ **Safety System** – Detects and prioritizes environmental sounds like alarms and glass breaking  
✅ **Parent Dashboard** – Sends alerts and reports on child progress and safety events  

---

## 🧑‍💻 System Components
| Component | Description | Tech |
|------------|-------------|------|
| **Sign Recognition Module** | Real-time detection of sign gestures | MediaPipe, TensorFlow |
| **Emotion Detection** | Detects child’s emotions using CNN + LSTM | OpenCV, Keras |
| **Interactive Learning Tool** | Game-based sign practice and feedback | React, Flask |
| **Safety Alert System** | Detects and prioritizes sounds | Audio Spectrogram Transformer (AST) |
| **Parent App** | Displays alerts, learning progress, and emotional status | React Native / Flutter |
